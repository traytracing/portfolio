xv6 Operating System

MIT 6.1810 ↗

C · RISC-V · xv6 · QEMU · GitFeb 2026 – Present

  • Implemented low level operating system utilities in C for xv6, a Unix like RISC-V teaching kernel run under QEMU, working directly against its system call interface (MIT 6.1810 Unix Utilities Lab).
  • Built a bounds safe memory inspection utility in C that interprets raw bytes as 8, 16, 32, and 64 bit values through typed pointers, preventing reads beyond valid memory regions while supporting strings and pointer backed data.
  • Extended find with command execution using fork, exec, and wait, creating child processes for matched files and integrating process creation, argument construction, and synchronization within the xv6 environment.
  • Built Unix style utilities including sleep, numeric file processing, and recursive find, using low level system calls such as open, read, fstat, and pause while handling command line arguments, file descriptors, and directory structures in C.

  • Built a Minecraft mod and Java backend data pipeline that flags underpriced Buy It Now auctions on Hypixel SkyBlock in 200 ms per API refresh by comparing new listings against recent sales.
  • Ingested 100,000 auction objects per minute (144 million per day) across 100 API pages with parallel pollers, parsing each page in under 10 ms with Fastjson and a full refresh in under 200 ms.
  • Published raw listings to Kafka and deduplicated them against a Redis set of seen auction IDs, dropping repeat listings from overlapping pollers before any downstream work.
  • Indexed listings in PostgreSQL and served reference price lookups from a read replica in under 5 ms, streaming flips through a second Kafka topic to mod and website clients over WebSocket.
